Tutoriais de Realidade Aumentada para a Indústria 5.0

Uma aplicação móvel que permite criar, editar e visualizar tutoriais interativos em RA — sem escrever código, sem modelar em 3D.

Desenvolvida em Unity + Vuforia para Android, a solução usa marcadores de imagem para sobrepor instruções virtuais a equipamentos reais, apoiando treinamento, manutenção e transferência de conhecimento.

Sobre o projeto

O que a aplicação faz

A aplicação utiliza Realidade Aumentada baseada em marcadores (Image Targets) para posicionar objetos virtuais sobre equipamentos reais, orientando usuários durante procedimentos operacionais, manutenção, treinamento e transferência de conhecimento.

🛠️

Criadores de tutoriais

Usuários sem conhecimento em programação, modelagem 3D ou desenvolvimento de RA conseguem montar tutoriais completos diretamente no smartphone.

📱

Usuários finais

Visualizam e executam os procedimentos em campo, com objetos virtuais sobrepostos ao equipamento real através da câmera do dispositivo.

Funcionalidades

Gerenciamento completo de tutoriais e tarefas

Ferramentas de criação e edição pensadas para quem não tem background técnico, além de uma biblioteca de objetos virtuais configuráveis.

📋

Tutoriais

Criar, editar, renomear, excluir e filtrar tutoriais completos.

✅

Tarefas

Criar, editar, excluir, reordenar e pré-visualizar cada etapa do procedimento.

🧩

Objetos virtuais

Setas direcionais, indicadores de atenção/correto/incorreto/proibição, texto 3D e ferramentas virtuais, cada um com posição, rotação, escala, cor e texto configuráveis.

Arquitetura

Como o sistema é organizado

O banco de dados armazena tutoriais, tarefas, objetos virtuais e suas configurações; o repositório de objetos guarda os modelos e recursos usados nos tutoriais.

Usuário │ ▼ Aplicação Android (Unity + Vuforia) │ ├── Banco de Dados │ (MongoDB Atlas) │ └── Repositório de Objetos (Asset Bundles)

Como executar

Compilando o projeto

Requisitos: Unity 2022 LTS ou superior, Android SDK, OpenJDK e Android Build Support.

1

Configurar o banco de dados

Criar conta e cluster no MongoDB Atlas, criar o banco de dados e a coleção de tutoriais, configurar usuário e IPs autorizados.

2

Conectar a connection string

Inserir a Connection String do MongoDB nos scripts responsáveis pela conexão com o banco.

3

Configurar o repositório de objetos

Hospedar os Asset Bundles (Google Drive, Azure Blob Storage, AWS S3, servidor HTTP ou NAS corporativo) e associar as URLs aos registros no banco.

4

Gerar o build

No Unity: File → Build Settings → Android → Switch Platform → Build (ou Build App Bundle para o Google Play).
