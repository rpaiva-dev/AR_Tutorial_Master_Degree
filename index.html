Augmented Reality Tutorials for Industry 5.0

A mobile application that lets you create, edit and view interactive AR tutorials — no code, no 3D modeling required.

Built with Unity + Vuforia for Android, the solution uses image targets to overlay virtual instructions onto real equipment, supporting training, maintenance and knowledge transfer.

About the project

What the application does

The application uses marker-based Augmented Reality (Image Targets) to place virtual objects over real equipment, guiding users through operating procedures, maintenance, training and knowledge transfer.

🛠️

Tutorial creators

Users with no background in programming, 3D modeling or AR development can build complete tutorials directly on their smartphone.

📱

End users

View and execute procedures in the field, with virtual objects overlaid on the real equipment through the device camera.

Features

Complete tutorial and task management

Creation and editing tools designed for people without a technical background, plus a library of configurable virtual objects.

📋

Tutorials

Create, edit, rename, delete and filter complete tutorials.

✅

Tasks

Create, edit, delete, reorder and preview each step of the procedure.

🧩

Virtual objects

Directional arrows, attention/correct/incorrect/prohibition indicators, 3D text and virtual tools, each with configurable position, rotation, scale, color and text.

How the system is organized

Getting started

Building the project

Requirements: Unity 2022 LTS or later, Android SDK, OpenJDK and Android Build Support.

1

Set up the database

Create an account and cluster on MongoDB Atlas, create the database and the tutorials collection, configure a user and authorized IPs.

2

Connect the connection string

Insert the MongoDB connection string into the scripts responsible for the database connection.

3

Set up the object repository

Host the asset bundles (Google Drive, Azure Blob Storage, AWS S3, HTTP server or corporate NAS) and associate the URLs with the database records.

4

Generate the build

In Unity: File → Build Settings → Android → Switch Platform → Build (or Build App Bundle for Google Play).
